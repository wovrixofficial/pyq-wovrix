LEARNOSHA LOGO KIT
Naming: learnosha-<type>-<version>[-size].svg/png
Versions: color = full colour (use on light backgrounds) | reversed = for dark backgrounds
          black = one colour, dark | white = one colour, light (for dark or busy backgrounds)
Always prefer SVG (sharp at any size). PNGs have transparent backgrounds except icons/avatars/social image.

01-logo-horizontal    icon + name side by side (website header, footer, documents)
02-logo-stacked       icon above name (posters, covers, square spaces)
03-icon-square        rounded square app icon (app stores, thumbnails)
04-icon-round         circle logo (profile pictures, round badges); includes ring version
05-symbol-only        the L mark with no box (watermarks, small corners)
06-favicon-and-app-icons   favicon.ico/svg, 16/32/48 px, apple-touch-icon, icon-192/512
07-social-media       full-bleed avatars (platforms crop to a circle) + OG share image 1200x630

Website <head>:
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<meta property="og:image" content="https://learnosha.in/og-image.png">   (rename the 1200x630 file to og-image.png)
