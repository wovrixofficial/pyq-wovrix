Assertion (A): Consider a Linear Programming Problem with minimise $Z = x + 2y$ subject to constraints $2x + y \geq 3, x + 2y \geq 6, x, y \geq 0$ which gives minimum $Z$ at infinitely many points. The corner points of feasible region are $(0, 3)$ and $(6, 0)$.

Reason (R): If two corner points produce the same minimum value of the objective function, then every point on the line segment joining the points will give the same minimum value.

Step 1 (Analysis of Constraints and Feasible Region): [0.25 Mark]

The given constraints are:

  • $2x + y \geq 3$
  • $x + 2y \geq 6$
  • $x, y \geq 0$

To find the corner points, we solve the boundary equations:

  • For $2x + y = 3$: If $x=0, y=3$; if $y=0, x=1.5$.
  • For $x + 2y = 6$: If $x=0, y=3$; if $y=0, x=6$.
  • Intersection point: Solving $2x + y = 3$ and $x + 2y = 6$, we get $x=0, y=3$.

The feasible region is unbounded. The corner points are $(0, 3)$ and $(6, 0)$.

Step 2 (Evaluation of Objective Function): [0.5 Mark]

We evaluate $Z = x + 2y$ at the corner points:

  • At $(0, 3)$: $Z = 0 + 2(3) = 6$
  • At $(6, 0)$: $Z = 6 + 2(0) = 6$

Since the minimum value is $6$ at both corner points, and the objective function $Z = x + 2y$ is parallel to the constraint line $x + 2y = 6$, every point on the line segment joining $(0, 3)$ and $(6, 0)$ yields the same minimum value $Z = 6$. Thus, Assertion (A) is True.

Step 3 (Final Concluded Answer): [0.25 Mark]

Reason (R) is a standard theorem in Linear Programming stating that if the optimal value occurs at two corner points, it occurs at every point on the segment joining them. Since (A) is true and (R) is the correct explanation for (A), the correct option is:

Both (A) and (R) are true and (R) is the correct explanation of (A).

💡 EL10 Concept Insight: Imagine the objective function is a flat tilted board; if it touches two corners of a shape at the exact same height, it must be resting perfectly flat along the entire edge connecting those two corners, making every point on that edge an "optimal" spot.
