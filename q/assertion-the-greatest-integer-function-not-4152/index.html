Assertion (A) : $f(x) = [x]$, $x \in \mathbb{R}$, the greatest integer function is not differentiable at $x = 2$. Reason (R) : The greatest integer function is not continuous at any integral value.
✓ Verified CBSE Marking Scheme Official Evaluation Steps & EL10 Insight

Question Analysis: Assertion (A) and Reason (R) based on the properties of the Greatest Integer Function $f(x) = [x]$.

Step 1 (Governing Law & Definitions): [0.25 Mark]

  • Definition of Continuity: A function $f(x)$ is continuous at $x = a$ if $\lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = f(a)$.
  • Definition of Differentiability: A function $f(x)$ is differentiable at $x = a$ only if it is continuous at $x = a$.

Step 2 (Step-by-Step Mathematical Working): [0.5 Mark]

  • Evaluating Reason (R): For any integer $n \in \mathbb{Z}$: $$\lim_{x \to n^-} [x] = n - 1$$ $$\lim_{x \to n^+} [x] = n$$ Since $\lim_{x \to n^-} [x] \neq \lim_{x \to n^+} [x]$, the function $f(x) = [x]$ is discontinuous at all integral values. Thus, Reason (R) is True.
  • Evaluating Assertion (A): Since $x = 2$ is an integer, the function is discontinuous at $x = 2$. By the theorem "Differentiability implies Continuity" (or its contrapositive "Discontinuity implies Non-differentiability"), the function is not differentiable at $x = 2$. Thus, Assertion (A) is True.

Step 3 (Final Concluded Answer): [0.25 Mark]

Since both Assertion (A) and Reason (R) are true, and Reason (R) is the correct explanation for Assertion (A) (because non-differentiability at integers is a direct consequence of the discontinuity at those points), the correct option is:

Both (A) and (R) are true and (R) is the correct explanation of (A).

💡 EL10 Concept Insight: Think of the greatest integer function like a staircase; because there is a "jump" or a gap at every whole number, you can't draw a smooth curve through those points, which makes it impossible to calculate a slope (derivative) there.
