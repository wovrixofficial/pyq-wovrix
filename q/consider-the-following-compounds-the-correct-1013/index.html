Consider the following compounds : $\text{C}_2\text{H}_5\text{NH}_2, (\text{C}_2\text{H}_5)_2\text{NH}, \text{C}_6\text{H}_5\text{CH}_2\text{NH}_2, \text{NH}_3, \text{C}_6\text{H}_5\text{NH}_2$ The correct increasing order of the above compounds on the basis of their basic strength is : (A) $\text{C}_6\text{H}_5\text{NH}_2 < \text{NH}_3 < \text{C}_6\text{H}_5\text{CH}_2\text{NH}_2 < \text{C}_2\text{H}_5\text{NH}_2 < (\text{C}_2\text{H}_5)_2\text{NH}$ (B) $\text{NH}_3 < \text{C}_6\text{H}_5\text{NH}_2 < \text{C}_6\text{H}_5\text{CH}_2\text{NH}_2 < \text{C}_2\text{H}_5\text{NH}_2 < (\text{C}_2\text{H}_5)_2\text{NH}$ (C) $\text{C}_6\text{H}_5\text{CH}_2\text{NH}_2 < (\text{C}_2\text{H}_5)_2\text{NH} < \text{NH}_3 < \text{C}_6\text{H}_5\text{NH}_2 < \text{C}_2\text{H}_5\text{NH}_2$ (D) $\text{C}_2\text{H}_5\text{NH}_2 < \text{C}_6\text{H}_5\text{NH}_2 < \text{NH}_3 < \text{C}_6\text{H}_5\text{CH}_2\text{NH}_2 < (\text{C}_2\text{H}_5)_2\text{NH}$
