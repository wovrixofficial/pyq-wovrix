If $f(x) = \begin{cases} 3x - 2, & 0 < x \leq 1 \\ 2x^2 + ax, & 1 < x < 2 \end{cases}$ is continuous for $x \in (0, 2)$, then $a$ is equal to: (A) $-4$ (B) $-\frac{7}{2}$ (C) $-2$ (D) $-1$
✓ Verified CBSE Marking Scheme Official Evaluation Steps & EL10 Insight

Step 1 (Formula / Governing Law & Given Data): [1/3 Mark]

For a function $f(x)$ to be continuous at a point $x = c$, the left-hand limit (LHL), right-hand limit (RHL), and the value of the function at that point must be equal:

$$\lim_{x \to c^-} f(x) = \lim_{x \to c^+} f(x) = f(c)$$

Given that $f(x)$ is continuous on $(0, 2)$, it must be continuous at the transition point $x = 1$.

Step 2 (Step-by-Step Mathematical Working): [1/3 Mark]

Calculate the LHL and RHL at $x = 1$:

  • LHL at $x = 1$: $$\lim_{x \to 1^-} f(x) = \lim_{x \to 1} (3x - 2) = 3(1) - 2 = 1$$
  • RHL at $x = 1$: $$\lim_{x \to 1^+} f(x) = \lim_{x \to 1} (2x^2 + ax) = 2(1)^2 + a(1) = 2 + a$$

Since the function is continuous at $x = 1$, we equate the limits:

$$1 = 2 + a$$ $$a = 1 - 2$$ $$a = -1$$

Step 3 (Final Concluded Answer): [1/3 Mark]

The value of $a$ is -1. Therefore, the correct option is (D).

💡 EL10 Concept Insight: Imagine the graph of the function is a line that needs to connect perfectly to a curve at $x=1$; for there to be no "jump" or break in the line, the height of the line from the left must exactly match the height of the curve from the right at that specific spot.
