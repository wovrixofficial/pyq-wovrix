(a) Find $\frac{dy}{dx}$, if $(\cos x)^y = (\cos y)^x$. OR (b) If $\sqrt{1-x^2} + \sqrt{1-y^2} = a(x-y)$, prove that $\frac{dy}{dx} = \sqrt{\frac{1-y^2}{1-x^2}}$.

Solution for CBSE Class 12 Mathematics

Part (a): Finding $\frac{dy}{dx}$ for $(\cos x)^y = (\cos y)^x$

Step 1 (Logarithmic Differentiation Principle): [1 Mark]

Since the variables are in the exponent, we apply the natural logarithm on both sides to simplify the expression using the property $\ln(a^b) = b \ln a$.

$$y \ln(\cos x) = x \ln(\cos y)$$

Step 2 (Step-by-Step Differentiation): [1.5 Marks]

Differentiating both sides with respect to $x$ using the Product Rule $\frac{d}{dx}(uv) = u \frac{dv}{dx} + v \frac{du}{dx}$ and Chain Rule:

$$\frac{d}{dx}[y \ln(\cos x)] = \frac{d}{dx}[x \ln(\cos y)]$$ $$y \cdot \left( \frac{1}{\cos x} \cdot (-\sin x) \right) + \ln(\cos x) \cdot \frac{dy}{dx} = x \cdot \left( \frac{1}{\cos y} \cdot (-\sin y) \cdot \frac{dy}{dx} \right) + \ln(\cos y) \cdot 1$$ $$-y \tan x + \ln(\cos x) \frac{dy}{dx} = -x \tan y \frac{dy}{dx} + \ln(\cos y)$$

Step 3 (Final Concluded Answer): [0.5 Mark]

Grouping the $\frac{dy}{dx}$ terms together:

$$\frac{dy}{dx} [\ln(\cos x) + x \tan y] = \ln(\cos y) + y \tan x$$ $$\frac{dy}{dx} = \frac{\ln(\cos y) + y \tan x}{\ln(\cos x) + x \tan y}$$

$$\cos \theta + \cos \phi = a(\sin \theta - \sin \phi)$$
