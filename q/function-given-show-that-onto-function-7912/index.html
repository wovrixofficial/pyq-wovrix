A function f: [-4, 4] $\rightarrow$ [0, 4] is given by f(x) = $\sqrt{16 - x^2}$. Show that f is an onto function but not a one-one function. Further, find all possible values of 'a' for which f(a) = $\sqrt{7}$.

CBSE Class 12 Mathematics: Solution & Marking Scheme

Question: A function $f: [-4, 4] \rightarrow [0, 4]$ is given by $f(x) = \sqrt{16 - x^2}$. Show that $f$ is onto but not one-one. Find all values of $a$ for which $f(a) = \sqrt{7}$.

Step 1 (Definition of One-One and Onto): [1 Mark]

  • One-One (Injective): A function $f$ is one-one if $f(x_1) = f(x_2) \implies x_1 = x_2$ for all $x_1, x_2$ in the domain.
  • Onto (Surjective): A function $f$ is onto if for every $y \in \text{Codomain}$, there exists at least one $x \in \text{Domain}$ such that $f(x) = y$.

Step 2 (Mathematical Proof): [2 Marks]

(i) Checking for One-One:

Let $x_1 = 2$ and $x_2 = -2$. Both are in the domain $[-4, 4]$.

$$f(2) = \sqrt{16 - (2)^2} = \sqrt{16 - 4} = \sqrt{12}$$ $$f(-2) = \sqrt{16 - (-2)^2} = \sqrt{16 - 4} = \sqrt{12}$$

Since $f(2) = f(-2)$ but $2 \neq -2$, the function is not one-one.

(ii) Checking for Onto:

Let $y \in [0, 4]$. We set $y = \sqrt{16 - x^2}$.

$$y^2 = 16 - x^2 \implies x^2 = 16 - y^2 \implies x = \pm \sqrt{16 - y^2}$$

Since $y \in [0, 4]$, $y^2 \in [0, 16]$, so $16 - y^2 \geq 0$. Thus, $x$ is always a real number in the interval $[-4, 4]$. Since every $y$ in the codomain has a pre-image $x$ in the domain, the function is onto.

Step 3 (Solving for 'a'): [1 Mark]

Given $f(a) = \sqrt{7}$:

$$\sqrt{16 - a^2} = \sqrt{7}$$

Squaring both sides:

$$16 - a^2 = 7$$ $$a^2 = 16 - 7 = 9$$ $$a = \pm 3$$

Both $3$ and $-3$ lie within the domain $[-4, 4]$. Therefore, the possible values are $a = 3, -3$.

💡 EL10 Concept Insight: Think of the function as a machine that squares numbers and subtracts them from 16; because squaring a negative number (like -2) gives the same result as a positive number (like 2), the machine can't tell them apart, which is why it fails the "one-one" test!
