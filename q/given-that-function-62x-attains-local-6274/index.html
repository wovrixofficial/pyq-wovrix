Mathematics Applications of Derivatives 5 Marks
Appeared in: 2024 (3 sets)
(a) It is given that function $f(x) = x^4 - 62x^2 + ax + 9$ attains local maximum value at $x = 1$. Find the value of 'a', hence obtain all other points where the given function $f(x)$ attains local maximum or local minimum values. OR (b) The perimeter of a rectangular metallic sheet is $300 \text{ cm}$. It is rolled along one of its sides to form a cylinder. Find the dimensions of the rectangular sheet so that volume of cylinder so formed is maximum.
