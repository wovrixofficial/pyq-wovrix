In a school, the swimming pool is shaped as a cuboid, and the breadth of the pool is represented by line $\frac{-x + 2}{-5} = y = z - 3$. Two students A and B are swimming along the length of the pool. Based on the above information, answer the following questions : (i) If the path of student A is represented by line $\frac{x + 5}{1} = \frac{y + 3}{4} = \frac{z - 6}{-3p}$, find the value of p. (ii) Write the vector equation of the path of student B swimming parallel to the path of student A, if at a certain instant he passes through the point with coordinates $(2, 4, -1)$. (iii) (a) Find the foot of the perpendicular drawn from $(2, 4, -1)$ to the path represented by student A. OR (iii) (b) If a bird flies across the top of the swimming pool with its path represented by $\frac{x + 4}{2} = \frac{y + 3}{8} = \frac{z - 5}{-18}$, then find the shortest distance between its path and the path of student A.

CBSE Class 12 Mathematics: 3D Geometry Marking Scheme

Given Data:

  • Breadth of pool (Line $L_1$): $\frac{x-2}{5} = \frac{y}{1} = \frac{z-3}{1}$
  • Path of Student A (Line $L_2$): $\frac{x+5}{1} = \frac{y+3}{4} = \frac{z-6}{-3p}$

(i) Find the value of $p$

Step 1 (Concept): [0.5 Mark] Two lines are perpendicular if the dot product of their direction ratios is zero: $a_1a_2 + b_1b_2 + c_1c_2 = 0$. Since the breadth and length of a cuboid are perpendicular, the lines are perpendicular.

Step 2 (Working): [0.5 Mark] Direction ratios of $L_1$ are $(5, 1, 1)$ and $L_2$ are $(1, 4, -3p)$.

$$5(1) + 1(4) + 1(-3p) = 0$$ $$5 + 4 - 3p = 0 \implies 9 = 3p$$

Step 3 (Result): [0.5 Mark] $p = 3$.

(ii) Vector equation of path of Student B

Step 1 (Concept): [0.5 Mark] The vector equation of a line passing through point $\vec{a}$ and parallel to vector $\vec{b}$ is $\vec{r} = \vec{a} + \lambda\vec{b}$.

Step 2 (Working): [0.5 Mark] Point is $(2, 4, -1) \implies \vec{a} = 2\hat{i} + 4\hat{j} - \hat{k}$. Direction vector $\vec{b}$ is same as $L_2$ (with $p=3$), which is $\hat{i} + 4\hat{j} - 9\hat{k}$.

Step 3 (Result): [0.5 Mark] $\vec{r} = (2\hat{i} + 4\hat{j} - \hat{k}) + \lambda(\hat{i} + 4\hat{j} - 9\hat{k})$.

(iii) (b) Shortest distance between Bird's path and Student A's path

Step 1 (Formula): [0.5 Mark] Shortest distance $d = \left| \frac{(\vec{a_2} - \vec{a_1}) \cdot (\vec{b_1} \times \vec{b_2})}{|\vec{b_1} \times \vec{b_2}|} \right|$.

Step 2 (Working): [1.5 Marks]

  • $L_A: \vec{a_1} = -5\hat{i} - 3\hat{j} + 6\hat{k}, \vec{b_1} = \hat{i} + 4\hat{j} - 9\hat{k}$
  • $L_{Bird}: \vec{a_2} = -4\hat{i} - 3\hat{j} + 5\hat{k}, \vec{b_2} = 2\hat{i} + 8\hat{j} - 18\
