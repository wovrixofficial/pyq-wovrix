Solve the following Linear Programming Problem graphically : Maximize $Z = \frac{2x}{5} + \frac{3y}{10}$ subject to constraints $2x + y \leq 1000$ , $x + y \leq 800$ , $x, y \geq 0$.
✓ Verified CBSE Marking Scheme Official Evaluation Steps & EL10 Insight

Step 1 (Governing Constraints & Objective Function): [0.5 Mark]

The objective is to maximize the function $Z = \frac{2x}{5} + \frac{3y}{10}$ subject to the following constraints:

  • $2x + y \leq 1000$
  • $x + y \leq 800$
  • $x \geq 0, y \geq 0$ (Non-negativity constraints)

Step 2 (Step-by-Step Mathematical Working): [2 Marks]

First, we determine the boundary lines and their intersection points:

  • For $2x + y = 1000$: If $x=0, y=1000$; if $y=0, x=500$. Points: $(0, 1000)$ and $(500, 0)$.
  • For $x + y = 800$: If $x=0, y=800$; if $y=0, x=800$. Points: $(0, 800)$ and $(800, 0)$.

To find the intersection of the two lines, solve the system:

$$2x + y = 1000$$ $$x + y = 800$$

Subtracting the second equation from the first: $(2x - x) + (y - y) = 1000 - 800 \implies x = 200$.

Substituting $x = 200$ into $x + y = 800 \implies 200 + y = 800 \implies y = 600$.

The feasible region is bounded by the vertices: $(0, 0)$, $(500, 0)$, $(200, 600)$, and $(0, 800)$.

Evaluating $Z = 0.4x + 0.3y$ at these corner points:

  • At $(0, 0): Z = 0.4(0) + 0.3(0) = 0$
  • At $(500, 0): Z = 0.4(500) + 0.3(0) = 200$
  • At $(200, 600): Z = 0.4(200) + 0.3(600) = 80 + 180 = 260$
  • At $(0, 800): Z = 0.4(0) + 0.3(800) = 240$

Step 3 (Final Concluded Answer): [0.5 Mark]

Comparing the values of $Z$ at all corner points, the maximum value is $260$.

Conclusion: The maximum value of $Z$ is $260$ at the point $(200, 600)$.

💡 EL10 Concept Insight: Think of the feasible region as a "fenced-in" area on a graph; because the objective function is a straight line, the best possible result (the maximum) will always be found at one of the "corners" of that fence, so we just test those corners to find the winner.
