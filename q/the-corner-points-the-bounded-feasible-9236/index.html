The corner points of the bounded feasible region of an LPP are O(0, 0), A(250, 0), B(200, 50) and C(0, 175). If the maximum value of the objective function $Z = 2ax + by$ occurs at the points A(250, 0) and B(200, 50), then the relation between a and b is : (a) $2a = b$ (b) $2a = 3b$ (c) $a = b$ (d) $a = 2b$
✓ Verified CBSE Marking Scheme Official Evaluation Steps & EL10 Insight

Step 1 (Governing Principle): [1/3 Mark]

According to the Fundamental Theorem of Linear Programming, if the maximum value of an objective function $Z = ax + by$ occurs at two distinct corner points, then the value of $Z$ at these two points must be equal. Given $Z = 2ax + by$, we equate the values at points $A(250, 0)$ and $B(200, 50)$.

Step 2 (Mathematical Working): [1/3 Mark]

Calculate the value of $Z$ at point $A(250, 0)$:

$$Z_A = 2a(250) + b(0) = 500a$$

Calculate the value of $Z$ at point $B(200, 50)$:

$$Z_B = 2a(200) + b(50) = 400a + 50b$$

Since the maximum value occurs at both points, $Z_A = Z_B$:

$$500a = 400a + 50b$$ $$500a - 400a = 50b$$ $$100a = 50b$$ $$2a = b$$

Step 3 (Final Concluded Answer): [1/3 Mark]

Comparing the derived relation $2a = b$ with the given options, the correct choice is (a).

💡 EL10 Concept Insight:

Think of the objective function as a line sliding across the graph; when it hits two corners at the exact same time, it means the line is perfectly parallel to the edge connecting those two points, forcing the values at those corners to be identical.
