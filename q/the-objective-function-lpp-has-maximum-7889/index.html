The objective function $Z = ax + by$ of an LPP has maximum value $42$ at $(4, 6)$ and minimum value $19$ at $(3, 2)$. Which of the following is true ? (A) $a = 9, b = 1$ (B) $a = 5, b = 2$ (C) $a = 3, b = 5$ (D) $a = 5, b = 3$
✓ Verified CBSE Marking Scheme Official Evaluation Steps & EL10 Insight

Step 1 (Formula / Governing Law & Given Data): [1/3 Mark]

The objective function is defined as $Z = ax + by$. Since the function attains specific values at given points, we substitute the coordinates $(x, y)$ into the objective function to form a system of linear equations:

  • At $(4, 6)$, $Z = 42 \implies 4a + 6b = 42$
  • At $(3, 2)$, $Z = 19 \implies 3a + 2b = 19$

Step 2 (Step-by-Step Mathematical Working): [1/3 Mark]

Simplify the first equation by dividing by 2:

$$2a + 3b = 21 \quad \text{--- (i)}$$

The second equation is:

$$3a + 2b = 19 \quad \text{--- (ii)}$$

To solve for $a$ and $b$, multiply (i) by 3 and (ii) by 2:

$$6a + 9b = 63 \quad \text{--- (iii)}$$ $$6a + 4b = 38 \quad \text{--- (iv)}$$

Subtract (iv) from (iii):

$$(6a - 6a) + (9b - 4b) = 63 - 38$$ $$5b = 25 \implies b = 5$$

Substitute $b = 5$ into equation (ii):

$$3a + 2(5) = 19$$ $$3a + 10 = 19 \implies 3a = 9 \implies a = 3$$

Step 3 (Final Concluded Answer): [1/3 Mark]

The values obtained are $a = 3$ and $b = 5$. Comparing this with the given options, the correct choice is (C).

💡 EL10 Concept Insight: Think of the objective function as a balance scale; because we know exactly how much "weight" ($Z$) is produced by specific "ingredients" ($x$ and $y$), we can treat this like a simple puzzle to find the unknown values of $a$ and $b$ that make the math work for both points.
