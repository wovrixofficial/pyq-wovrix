(a) If $xy = e^{x - y}$, then find $\frac{dy}{dx}$. OR (b) Differentiate $\tan^{-1} \left$ \frac{\sqrt{1 + x^2} - \sqrt{1 - x^2}}{\sqrt{1 + x^2} + \sqrt{1 - x^2}} \right$$ with respect to $\cos^{-1} x^2$.
✓ Verified CBSE Marking Scheme Official Evaluation Steps & EL10 Insight

Solution (a)

Step 1 (Logarithmic Differentiation): [1 Mark]

Given the equation $xy = e^{x - y}$. Since the variables are in the exponent, we apply the natural logarithm ($\ln$) on both sides to simplify the expression:

$$\ln(xy) = \ln(e^{x - y})$$ $$\ln x + \ln y = x - y$$

Step 2 (Differentiation with respect to $x$): [1.5 Marks]

Differentiating both sides with respect to $x$:

$$\frac{d}{dx}(\ln x) + \frac{d}{dx}(\ln y) = \frac{d}{dx}(x) - \frac{d}{dx}(y)$$ $$\frac{1}{x} + \frac{1}{y} \frac{dy}{dx} = 1 - \frac{dy}{dx}$$

Grouping the $\frac{dy}{dx}$ terms on one side:

$$\frac{1}{y} \frac{dy}{dx} + \frac{dy}{dx} = 1 - \frac{1}{x}$$ $$\frac{dy}{dx} \left( \frac{1 + y}{y} \right) = \frac{x - 1}{x}$$

Step 3 (Final Concluded Answer): [0.5 Mark]

Solving for $\frac{dy}{dx}$:

$$\frac{dy}{dx} = \frac{y(x - 1)}{x(1 + y)}$$

💡 EL10 Concept Insight: Taking the log turns a messy multiplication and exponent problem into a simple addition problem, making it much easier to find the rate of change!

Solution (b)

Step 1 (Substitution Method): [1 Mark]

Let $x^2 = \cos \theta$, then $\theta = \cos^{-1} x^2$. The expression becomes:

$$y = \tan^{-1} \left( \frac{\sqrt{1 + \cos \theta} - \sqrt{1 - \cos \theta}}{\sqrt{1 + \cos \theta} + \sqrt{1 - \cos \theta}} \right)$$

Using half-angle identities ($1+\cos\theta = 2\cos^2\frac{\theta}{2}$ and $1-\cos\theta = 2\sin^2\frac{\theta}{2}$):

$$y = \tan^{-1} \left( \frac{\sqrt{2}\cos\frac{\theta}{2} - \sqrt{2}\sin\frac{\theta}{2}}{\sqrt{2}\cos\frac{\theta}{2} + \sqrt{2}\sin\frac{\theta}{2}} \right) = \tan^{-1} \left( \frac{1 - \tan\frac{\theta}{2}}{1 + \tan\frac{\theta}{2}} \right)$$

Step 2 (Simplification): [1.5 Marks]

Using the formula $\tan(\frac{\pi}{4} - A) = \frac{1 - \tan A}{1 + \tan A}$:

$$y = \tan^{-1} \left( \tan\left( \frac{\pi}{4} - \frac{\theta}{2} \right) \right) = \frac{\pi}{4} - \frac{\theta}{2}$$

Substitute $\theta = \cos^{-1} x^2$ back:

$$y = \frac{\pi}{4} - \frac{1}{2} \cos^{-1} x^2$$
