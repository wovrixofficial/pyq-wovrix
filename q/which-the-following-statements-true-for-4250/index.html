Which of the following statements is true for the function $f(x) = \begin{cases} x^2 + 3, & x \neq 0 \\ 1 &, x = 0 \end{cases}$ ? (A) $f(x)$ is continuous and differentiable $\forall \text{ x} \in \mathbb{R}$ (B) $f(x)$ is continuous $\forall \text{ x} \in \mathbb{R}$ (C) $f(x)$ is continuous and differentiable $\forall \text{ x} \in \mathbb{R} - \{0\}$ (D) $f(x)$ is discontinuous at infinitely many points
✓ Verified CBSE Marking Scheme Official Evaluation Steps & EL10 Insight

Step 1 (Governing Law & Definition): [0.25 Mark]

A function $f(x)$ is continuous at $x = a$ if and only if:

$$\lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = f(a)$$

For $x \neq 0$, $f(x) = x^2 + 3$, which is a polynomial function and is continuous and differentiable everywhere in its domain.

Step 2 (Step-by-Step Mathematical Working): [0.5 Mark]

We check the continuity at the point of interest, $x = 0$:

  • Left-Hand Limit (LHL): $\lim_{x \to 0^-} (x^2 + 3) = 0^2 + 3 = 3$
  • Right-Hand Limit (RHL): $\lim_{x \to 0^+} (x^2 + 3) = 0^2 + 3 = 3$
  • Functional Value: $f(0) = 1$ (given)

Since $\lim_{x \to 0} f(x) = 3$ and $f(0) = 1$, we observe that $\lim_{x \to 0} f(x) \neq f(0)$. Therefore, the function is discontinuous at $x = 0$.

However, for all $x \in \mathbb{R} - \{0\}$, the function is defined by $f(x) = x^2 + 3$, which is a polynomial. Polynomials are infinitely differentiable and continuous on their entire domain.

Step 3 (Final Concluded Answer): [0.25 Mark]

Since the function is continuous and differentiable for all $x$ except at $x=0$, the correct statement is:

(C) $f(x)$ is continuous and differentiable $\forall x \in \mathbb{R} - \{0\}$

💡 EL10 Concept Insight: Think of the graph as a smooth parabola with a hole at $x=0$, where a single point is "plucked" out and moved down to a different height; because the curve is smooth everywhere else, it remains perfectly continuous and differentiable everywhere except at that one broken spot.
